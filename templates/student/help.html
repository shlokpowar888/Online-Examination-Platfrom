Online Examination Rules & Technical Guidelines

Policies, proctoring requirements, technical troubleshooting, and institutional support

Academic Code of Conduct
1. Fullscreen Enforcement

The examination runtime initiates in mandatory fullscreen. Departing fullscreen triggers an immediate cautionary toast and notifies the faculty proctor via the real-time telemetry stream.

2. Tab Switching & Focus Loss Detection

Opening alternate browser tabs, switching applications, or interacting with background windows is strictly prohibited and logged with timestamp and duration metrics in the immutable audit ledger.

3. Server-Side Continuous Autosave

Your answers are transmitted and persisted to the institutional database upon every radio button or checkbox interaction. In the event of network disruption, you can reconnect without losing previously saved responses.

4. Server Countdown Expiry

Exam timers run synchronously against server time. When the scheduled time reaches zero, active submissions are sealed and submitted automatically.
